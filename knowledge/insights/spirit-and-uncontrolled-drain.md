# 정신력 활용과 조절 불가 소모원

정신력을 딜로 바꾸는 구조와, 소모율을 통제할 수 없는 자원 소모원의 취급.

- **실오라기 같은 빛(실타래 빛)은 총 정신력 기준이라 점유해도 딜이 깎이지 않는다 — 단 PoB 미구현이라 커스텀 모드 수동 입력이 필요하다** — §4 정신력 스태킹 — PoB 미구현은 조립 파이프라인에 직접 영향 *(라벨 IN_GAME)*
- **시신걸음은 1.2미터 이동마다 부패를 자동 시전하며 소모율을 조절할 수 없다 — 이동 속도가 곧 자원 소모율이다** — §4 시신걸음 *(라벨 IN_GAME)*
