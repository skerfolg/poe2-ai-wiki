# 화염구 (Fireball)

착탄 시 폭발하는 큰 화염 투사체 주문. **화염 주입(Fire Infusion)을 보유하고
있으면 소비해** 착탄 지점에서 작은 화염탄 고리를 사방으로 추가 발사한다.

## 메커니즘

- 기본형은 단일 투사체 + 소범위 폭발. 0.3.0부터 2차 화염탄은 기본 제공이
  아니라 **화염 주입 소비 시에만** 나온다 — 주입 생성 수단이 사실상 세트.
- 2차 화염탄은 1차와 **같은 대상을 다시 때릴 수 있다** (0.3.0 변경).
  근접 착탄일수록 다중 명중 기대값이 커진다.
- 2차 투사체는 추가 투사체 수정치의 영향을 받지 않는다 (0.2.0, 성능 사유).
- 3티어 젬, 시전 1.2초 — 묵직한 한 발 계열.

## 판단 노트 (생성기 관점)

- 주입 의존 스킬: "주입 생성 → 소비" 루프가 조립돼야 완전체 (RC1 유형 —
  생성 수단 없이 채택하면 반쪽 스킬).
- 시전이 느려 시전 속도/투사체 속도보다 **한 발의 크기**(피해 증폭·주입 확정)
  를 키우는 쪽이 정합.

## 패치 이력 요점

- 0.3.0: 2차 화염탄이 주입 소비제로 전환, 최소 젬 레벨 9→3, 기본·2차 피해
  대폭 상향, 2차가 같은 대상 타격 가능.
- 0.2.0: 격노하는 영혼(SRS) 상한 우회 제거, 2차 투사체에 추가 투사체 미적용.
- 0.1.0: 출시.
