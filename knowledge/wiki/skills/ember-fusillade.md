# 불씨 일제 사격 (Ember Fusillade)

화염 투사체 주문. 시전으로 불씨를 **축적**하고, 마지막 시전 후 **부유
대기시간**(기본 1.3초)이 지나면 불씨가 **순차 발사**된다 — 축적·부유·발사의
세 시간이 분리돼 있다.

## 재시전과 부유시간 초기화 (UNVERIFIED)

- **재시전하면 이미 활성인 불씨의 부유시간이 초기화될 수 있다** — 버튼을
  계속 누르는 방식은 발사를 지연시킬 수 있다는 가설. 실효 부유시간이 실제
  시전 간격보다 길면 재시전마다 타이머가 계속 리셋된다.
- 따라서 운용은 "짧게 눌러 축적 → 버튼을 놓고 이동 → 자동 발사"가 기본
  (v6 §9). 지속시간 감소(Forthcoming 휠 등)로 부유시간을 시전 간격보다
  짧게 만드는 것이 구조적 해결 후보.
- 시전 속도를 올리는 효과(Final Barrage 등)는 시전 간격을 부유시간보다
  짧게 만들어 오히려 발사를 지연시킬 수 있다 — 지속시간 감소와 함께 조정.

## 검증 항목 (인게임)

1. 재시전 시 이미 발사 중/부유 중인 불씨의 실제 동작
2. 실제 최대 불씨 수·시전당 생성 수
3. 최대 축적 후 첫 발까지 시간, 완전 일제 사격 1회의 총 시간
