# pob-snapshot

**정본 지침은 [AGENTS.md](../../../skills/pob-snapshot/AGENTS.md)다 — 먼저 그것을 읽고 순서를 그대로 따른다.**
이 워크플로는 저비용 에이전트로도 실행되도록 **재량을 제거한 절차**다. 순서를
벗어나지 말 것.

## 전제

- 레포 루트에서 실행, `.venv` 활성(또는 `.venv/bin/python`), `PYTHONPATH=src`
- `luajit` 사용 가능 (파싱 갭 감사가 PoB를 부팅한다)
- 새 커밋 SHA를 **사람에게서 받는다** — 임의로 최신을 고르지 말 것

## 절대 규칙

⛔ **기존 스냅샷을 덮거나 지우지 말 것** — 새 버전은 **새 클론**이다(AD-2/D4).
덮으면 옛 측정값을 재현할 방법이 사라진다.

⛔ **`knowledge/game-data/**`의 `sources[].pob`를 일괄 치환하지 말 것** — 그건 그
레코드를 언제 어느 커밋에서 긁었는가의 **증거**다. 스냅샷을 올렸다고 덮으면 계보가
거짓이 된다.

⛔ **테스트 기대값을 먼저 고치지 말 것** — 계산값이 달라졌다면 그건 PoB가 계산을
바꾼 것이고, **보고 대상**이지 수선 대상이 아니다.

## 잊으면 조용히 틀리는 것

스냅샷이 바뀌면 PoB가 읽는 문구도 바뀐다 → 파싱 갭 표기가 낡는다.
`PYTHONPATH=src python -m pok.pob.parse_gaps`를 **반드시** 다시 돌린다(절차 3).
안 돌리면 통합 테스트가 막지만, 막힌 뒤에 도는 건 낭비다.
