## 확인 범위와 한계

실제 최종물8개를 원문 그대로 재계산하고 활성 트리 할당을 대조했으며 장비135항목(원문120개)을 정식 도구로 검사했다. H1 변경 전·단순 장착·최종6입력을 독립 재계산했고 두 최종 투영본의 모든 숫자 스탯이 원본 XML과 같았다. H2 준비기/유틸13개는 원래 설정에서 선택 스킬만 바꾼 별도 진단이다. 이를 실제 회전이나 군 간 동일 조건 비교로 부르지 않는다.

FreezeBuildupAvg/HeavyStunBuildupAvg는 이미 퍼센트다. 작은 수치를100배 키우거나 발사체 수를 중첩 실측 없이 곱하지 않았다. 고유 적의 Primed for Freeze는70%이며 징표 경로를 일반100% 동결과 같다고 처리하지 않았다. 낮은 모델 축적만으로 게임에서 불가능하다고 단정하지도 않는다.

원본 전달 실패와 미완료/미제출은 별도 기술 원장에 남는다. 구조화 기록과 자유 서술은 동등하게 읽으며 문서 길이·고유 개수·ready·도구 횟수·DPS 순위를 가점으로 쓰지 않았다. 점수 신뢰도는 중간이며 전역 경로/장비 최적이나 실제 게임 가동률은 미확인이다.
