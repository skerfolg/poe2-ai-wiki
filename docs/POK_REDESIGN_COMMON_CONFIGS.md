# PoK R1 — 같은 config의 첫 공격 스냅샷

2026-10-31. [원본 조건 검증](POK_REDESIGN_RESULTS.md)과 분리한 후속 측정이다.
조건·한계는 [검증 원장](POK_REDESIGN_VALIDATION.md)의 공통 config 사전 고정 절에 있다.

14개 계산 모두 저장된20개 config가 해당 프로파일과 정확히 같고 나머지 빌드 입력은 그대로임을 확인했다.
Pinnacle·레벨82, 이동 중, 시작 생명력/ES 보유를 요청한 첫 공격이며 사전 격노·처치·최근 치명타 등은 껐다.
1m와4m를 각각 보존한다. 평균 맵핑·보스 지속전·실전 범위/중첩·미모델링 방어의 측정이 아니다.
각 공통 조건 셀은 독립 환경의1회 계산이다. 앞서35회 반복한 것은 원본 config이며 이14개 셀의 반복 검증으로 소급하지 않는다.
이 두 거리에서는7개 시안 모두 명중100%와 같은 DPS가 나왔다. 이를 실제 게임에서 거리가 무관하다는 증거로 해석하지 않는다.

우열을 결정하지 않는다. 실제 링크의 근거·대안 비용·전체 재설계와 사용자 선호를 함께 대조해야 한다.
AI 기술 검토의 불완전 맹검과 입력/계산의 알려진 한계도 유지한다. #188 해결이나 개선 효과 입증으로 사용하지 않는다.

`redesign-r1-evaluation/measurements/common-config-summary.json` 및 해당 하위 실행 기록에 있다.
