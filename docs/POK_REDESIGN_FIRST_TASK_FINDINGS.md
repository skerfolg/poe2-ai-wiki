# R1 첫 과제 — 원인 가설의 잠정 대조

2026-10-31. [초기 기술 평가](POK_REDESIGN_QUALITY_REVIEW.md) · [수행/한계](POK_REDESIGN_VALIDATION.md).

첫 과제8회에 한정한 기술 검토다. 사용자 선호 평가·추가 두 과제·앵커 기록 시험은 남아 있다.
절차를 제거하면 좋아진다거나 도구 전면 폐기가 답이라는 결론을 입증하지 않았다.

## 가설별 근거

### H1 — 절차/관문이 자유도를 빼앗아 품질을 낮춘다

일률적 저하 주장은 미지지; 부담 가능성은 남음.

관측:
- P의2회 모두 시간 상한에 가까웠고1회 최종 응답이 없었다.
- P-2의3133호출 중2698개는 저장 결과 회수였다.

반증/한계:
- 완주한 P-1은 장비/트리/보조를 함께 바꾸고 실제 대가를 제시했다. 초기6축 검토는 사고 확장이 사라졌다는 서술과 맞지 않는다.
- O/P는 스킬 지침·추천 관문의 묶음 비교이며 규칙/도움말의 정보량도 다르다. 절차만의 순수 효과가 아니다.

구현 연결: 사실 검증/유용한 지침은 유지하되 호출 이력·정해진 순서를 최종 근거와 동일시하지 않는 계약을 시험한다.

### H2 — 컨셉 운 또는 실험 편차

반복별 편차는 관측; 컨셉 운 하나로 설명 불가.

관측:
- F/O/R에서 같은 군의 두 실행도 선택과 자원/방어 구성이 달랐다.
- 7개 최종안은 모두 Storm Wave Invoker지만 CI/하이브리드, 재생/흡수, 장비·주얼·이동 선택이 다르다.

반증/한계:
- 각2회이며 사용자 실물 평가가 아직 없다. 정성 점수 차이를 통계적 효과로 읽을 수 없다.
- 원래#188 브리프/실행 환경의 정확한 재현이 아니다.

구현 연결: 한 번의 승패를 원인으로 단정하지 않고 추가 두 과제와 R5 보류 과제에서 재평가한다.

### H3 — 최적화 도구 자체가 잘못 설계됐다

전면 무효 주장은 미지지; 국소 범위/선택 재개방 문제는 유효한 개선 대상.

관측:
- O/P에서 실제 optimizer 사용을 확인했다. O는 일부만 사용했고 P는 더 많은 종류/후속 비교를 사용했다.
- 기존 고정 노드 성장·한 부위 탐색의 범위는 전역 재설계와 다르다.

반증/한계:
- 최적화 미제공 F에서도 합리적인 묶음 재투자가 있었고, 제공/절차군에서도 그 선택이 있었다.
- 사용 여부만으로 채택 품질이나 공동 재설계 성공을 보장하지 않는다. 최종값도 실제 비교 범위와 분리해야 한다.

구현 연결: 유한 탐색은 선택 기능으로 재사용하고 실제 후보/고정 기반/미지원/기한을 반환한다. 묶음 변경과 대체 근거를 허용한다.

### H4 — 누적 수정/결함이 빌드를 꼬이게 했다

구체적 결함 관측; 모든 품질 차이의 원인이라고 확정하지 않음.

관측:
- #203은 유효한 내장 트리거에 잘못된 수정 지시를 내고 #204는 승인된 제외 보조를 신고하지 않았다.
- 저장 결과 회수와 입력/모델 공백 구분의 비용/모호성이 관측됐다.

반증/한계:
- 7개 최종 저장본은 원본과 공통 조건에서 계산됐고119개 아이템 검사/35회 원본 반복이 일치했다.
- fresh/순차 검증은 기존#189 병렬/수명 결함을 해결했다고 증명하지 않는다.

구현 연결: 측정값·카탈로그 적법성·정보부족·모델링/입력 경로를 분리하고 재현된 결함을 계약/회귀와 함께 R3에서 고친다.

### H5 — 사용자 목표가 도구 지표로 축소됐다

목표 축소 위험은 있으나 모든 실행에 대한 설명은 아님.

관측:
- DPS·ready·전수 호출 수만으로 좋은 이동/회복 구성을 고를 수 없었다.
- 자체20만 목표는 사용자 하드 조건이 아니고 보스 피해와 팩 범위도 구분해야 한다.

반증/한계:
- 여러 시안이 Mobility/면역/재충전/여유를 위해 실제 DPS를 포기했고 이를 명시했다.

구현 연결: 목표/필수 조건/잠정 공급자/성능 후보를 분리한 설계 기록과 다차원 실물 검토를 시험한다.

## 유지할 판단

검증된 기본 조회/계산/비교를 버리는 방향은 근거가 약하다. 재설계의 핵심은 도구를 더 강제로
호출시키는 것이 아니라 입력에 결박한 사실·근거·한계와 설계 선택을 연결하는 계약이다.
좋은 결과가 나온 절차군1회와 미제출1회를 둘 다 보존하고, 선택 최적화군/기본군/참고군의
차이도 완료율 하나나 DPS 하나로 환원하지 않는다. R은 자료/인터페이스 비대칭 때문에 순수 인과 대조가 아니다.

이 결과는 합의한 R2 계약 설계의 입력이다. 효과 입증은 이후 대표 과제·UI 통합·전환 검증까지
수행한 뒤 평가한다. R1 추가 시험과 R2~R7을 완료했다고 보고하지 않는다.
