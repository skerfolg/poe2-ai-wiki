이 문서는 참조 정답 목록이 아니라 실행/비교 방법을 고정한다.

## 입력과 분리

새 생성 입력은 젬링 리저네어·아이스샷·격노 스태킹 세 조건뿐이다. 투자 수준·보유
장비·방어 방식·특정 고유/혈통/주얼을 추가 고정하지 않는다. 이전 결과를 정답으로
주입하지 않는다. 모델은 같은 gpt-6-astra/ultra와 최신 로컬 PoK를 사용한다.
생성은 1~3단계까지만, 전체90분 내에서 수행한다. 실행 중 코드를 고치거나 운영자가
후보·공급자·정답을 넣지 않는다. 좌초하면 그대로 보존·보고한다. 코드의 기존 자동
체크포인트 재개는 같은 기한 안에서 허용하며 코드 보완을 통한 구제와 구분한다.

레퍼런스는 사용자가 지정한 `D:/4. Workspace/poe2-ai-wiki/artifacts/ice_shot_build.txt`다.
원본 SHA256과 크기만 사전 보존하고, 생성 결과를 동결한 뒤 본문을 읽는다. 원본을
생성 세션·입력 팩·프롬프트·MCP 파일 공간에 복사하지 않는다. 셸/앱·임의 로컬 파일
접근은 기존 실행기의 비활성 정책을 유지한다. 생성 세션의 MCP 저장 공간은 분리한다.
기존 KB·인사이트·공개 웹은 정상 사용한다. 이미 과거에 분석한 레퍼런스이므로
새 미공개 홀드아웃이나 지식 누설이 전혀 없는 일반화 시험으로 주장하지 않는다.

## 이번 지침 보완

직전 사용자 평가는 아이템/주얼·치명타 검토 부족과 자연 재생 편중이다. 이전 실행의
도구 인자·기록에서는 사용자가 지적한 치명타 성립기와 고가치 허리띠의 개별 검토를
찾지 못했다(조회 결과 이름에 잠깐 등장했을 가능성과 개별 검토를 구분한다).
결정적 sustain 검사는 1회 비용/가용량의 경계를 계산하며 자연 재생만을 강제하지 않는다.
무처치 보스 검토를 무플라스크·무한 지속 요구로 확장한 이전 판단을 수정한다.

일반 정책은 자원 장면별 공급/비축 소진, 비용 보조와 피해 슬롯의 손익, 치명타 및
대체 성립기, 고가치 조합의 현재 채택/기각 이유를 기록하도록 바꾼다. 특정 아이템을
이번 정답으로 넣지 않는다. 희귀 목표 접사와 고유 변형의 실물 보유에 서로 다른
증명 부담을 두지 않고 미파싱/미측정을0효과로 취급하지 않는다. planning-v2 검사는
검토 누락과 결정 참조를 확인하며 효과의 진실성·최적성을 인증하지 않는다.

## 비교 축과 판정

생성 제출을 동결한 뒤 기존 PoB를 읽기 전용으로 분석한다. 새 PoB·최적화·모방 수리는
하지 않는다. 레퍼런스의 저장 DPS나 복잡함 자체를 좋은 선택의 증거로 쓰지 않는다.

| 축 | 확인할 것 |
| --- | --- |
| 고정 조건 | 전직·주력 스킬·격노 스태킹의 실제 구현과 의존 |
| 격노 | 초기/반복 공급, 상한, 소비·만료·유지, 피해·유틸로의 보상 사슬 |
| 공격 | 무기 원천, 스킬 파트/전환, 배율 연결, 상태이상·저항 처리·타깃 조건 |
| 치명타 | 확률/보장·기본값·배율·명중 및 조건 가용성, 비치명타 대안 손익 |
| 아이템·주얼 | 옵션과 조합의 역할, 랜덤 변형/소켓/패시브·장비 슬롯 대가 |
| 보조·스킬 | 실제 링크·보조 적합성, 대체 효과·비용, 유틸/버프의 역할 |
| 방어·회복 | 피격·지속피해·상태이상과 조건이 꺼졌을 때의 방어 |
| 마나·운용 | 맵핑·보스·재시동의 재생/플라스크/명중·처치/비축·소모와 조작 비용 |
| 정신력 | 활성·부여원과 실제 점유, 전체 장부 및 기회비용 |
| 구현 제약 | 패시브 경로·선택 속성, 슬롯·배타·조건과 근거 범위 |

행별로 `같은 기능 포착` / `기능적 대안` / `누락` / `후보·보류에만 있음` /
`레퍼런스 의존·부적합 가능` / `판정 불가`를 구분한다. 단순 아이템 일치율이나 임의의
합성 점수로 결론 내리지 않는다. 대안의 질적 성립과 동등 이상의 성능은 다르므로
PoB 비교가 없으면 성능 우열은 미측정으로 남긴다. 잘못 추가한 필수 조건과 불필요한
기회비용, 고가치 효과를 보류에만 둔 이유도 별도 본다.

목걸이 부여 스킬의 중복 정신력 점유로 원본 정신력이 음수가 되는 문제는 사용자가
확인한 알려진 PoB 결함이다. 원본을 수정하거나 빌드 불성립으로 채점하지 않는다.
다른 실제 점유 누락까지 면제하지 않고 부여원·활성 상태를 구분한다.
