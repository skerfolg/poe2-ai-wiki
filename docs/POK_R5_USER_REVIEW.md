# R5 PoB 직접 검토 자료

최종 응답이 지정한 저장본5개다. 코드 필드의 손상된 문자열이나 운영자가 고른 중간안을
대신 넣지 않았다. PoB 가져오기에는 아래 파일의 전체 내용을 사용한다.
파일은 현재 PC의 artifacts에 있으며 GitHub 저장소에는 포함되지 않는다.

제품판 이름·자체 완료 상태·AI 점수는 이 페이지에 표시하지 않았다. 그러나 이미 진행
보고가 공개됐고 빌드 내용에서도 추론할 수 있으므로 완전한 맹검은 아니다.

H1은 레벨100 Stormweaver Spark, 완드+방패, 생명력+ES, CI/낮은 생명력 금지다.
Ring1은 제공한 일반판 Dream Fragments 원문으로 고정하고, 교체로 생긴 손익을 여러
부위·노드·젬에 재투자해야 한다. 이동 맵핑과 처치 없는 보스의 자원/회복도 목표다.

H2는 레벨100 Witchhunter 석궁, 생명력+방어도+회피, CI/낮은 생명력 금지다.
서로 다른 상태/자원/조건의 생산·소비가 두 기능 이상에서 연결되어야 한다.
첫 진입·다음 팩·무처치 보스·소비/만료/중단 후 복구와 행동 비용이 평가 대상이다.

두 과제 모두 일반123/전직8 이내·네 저항75% 이상·단일 고투자 구성이다.
매물/가격·다른 장비의 소유는 확인하지 않았다. 서로 다른 설정과 피해 단위이므로
표시 DPS가 큰 순서로 전체 품질을 정하지 않는다.

검토에서는 메커니즘, 장비, 패시브/주얼, 젬/유틸, 공동 재설계, 과제 적합성을 나누어
볼 수 있다. 특히 비효율적인 가지나 빈 슬롯, 불필요한 장비 고정, 끊기는 공급,
실제로 조작하기 어려운 연결을 표본 번호와 함께 기록하면 후속 설계에 반영할 수 있다.
인게임 관측이 있으면 조건·사용 장비·실패 상황을 함께 남긴다. PoB만 보고 확인한
선택 품질과 실제 플레이에서 확인한 사실은 구분한다.

공동 재설계의 전후 손익은 최종 파일 하나로 모두 판정할 수 없다. 별도 결과 보고서의
H1 세 시점 대조가 있으며 그 보고서에는 제품판 식별자가 표시되어 있다.

모든 파일은 독립 복원/계산과 알려진 적법성 검사를 거쳤지만 게임 성립·좋은 빌드라는
인증은 아니다. 사용자 평가가 없다는 사실을 AI 점수로 채우지 않는다.
