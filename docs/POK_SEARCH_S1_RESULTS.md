# S1 — 기존 설계 기록의 가정·근거·선택 연결

2026-11-05, 기준 dd6559f. 제품 코드 수정 없이 기존 경로를 검증했다.
게임 규칙이나 모델 품질 시험이 아닌 합성 기록의 변화 전파 검사다.

## 결과

`q-critical-supply` 질문을 연결했다. 질문 criterion은 공급이 불충분하면 공급 보강
묶음과 의존도가 낮은 공격을 비교한다는 판단 조건을 기록했다.

| 입력 변화 | 재검토 대상 |
|---|---|
| 질문만 open→resolved | 없음 |
| 선택 연결 없는 근거 추가 | 없음 |
| 근거 scope.decision_ids에 공급 가정 연결 | d-sustain, d-attack, d-defence |

실제 출력과 전후 sealed record는
`artifacts/reviews/search-revision-s1/dependency-probe.json`에 보존했다.
기존 관련 단위4개도 통과했다: 공급자 변경 전파, condition scope 연결,
evidence scope 연결, 의존 질문 재개방. pytest 캐시 생성 권한 경고는 있었으나 실패는 없다.

## 해석과 구현 결정

질문에 depends_on을 적는 것은 질문이 어떤 결정에 의존하는지 나타낸다. 질문 상태
변경이 그 결정을 자동으로 뒤집는 역방향 의존 선언은 아니다. 현재 동작을 즉시 결함으로
취급하면 단순히 질문을 닫는 행위까지 모든 선택의 변경 원인이 될 수 있다.

관측을 근거로 등록해 해당 가정에 연결하고, 가정에 의존하는 선택들을 연결하면 기존
전파가 작동한다. 따라서 이번 S1은 스키마·솔버 추가 없이 종료한다. 에이전트가
근거를 연결하지 않거나 불리함을 이해하지 못하는 문제는 남으며 S3 평가 대상이다.
엔진은 임의 숫자로 성립/채택을 판정하지 않는다.

합성 fixture의 측정 참조는 실제 측정의 인증이 아니며 게임 성립은 not_checked다.
실제 평가에서는 저장된 측정/출처와 유효한 참조를 사용한다. 이 결과만으로 H2 품질
실패가 해결됐다고 주장하지 않는다.
