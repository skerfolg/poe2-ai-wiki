## 사전 판정 기준

최종물을 가려진 sample 이름으로 먼저 읽고 실제 XML/설계/근거를 대조한다.
운영자는 정책을 이미 알고 있어 완전 맹검은 아니며 이 한계를 결과에 표시한다.
외부 최상위 참조와의 동가격 성능 우월성을 이4회로 주장하지 않는다. 사용자 실물
검토는 별도로 받아 기술 평가와 함께 최종 채택에 반영한다.

1. 전달/완성: 실제 최종 PoB·XML 일치, 제약/입력/선택 모드·문서 일치. 미제출을
   좋은 중간안으로 대체하지 않는다. 완성했다고 쓴 말은 통과 근거가 아니다.
2. 조합: 제공된 핵심 재료의 대가와 활용을 함께 계산한 실제 구성인가. 단독 변경
   비교와 여러 영역 재배분의 범위를 구분한다. 부품 수·고유 수는 점수가 아니다.
3. 측정 해석: 소환수/플레이어/총합, 사건/반복, 공급/소비, 실제/미모델링을 구분했는가.
4. 선택: 핵심 가정이 불리할 때 보강/대체/유지의 이유와 실제 실물 변경이 연결되는가.
   정확한 경고만 적고 핵심 실패를 방치했다면 개선 성공으로 인정하지 않는다.
5. 목적 적합성: 피해·방어·회복·자원·조작의 대가를 함께 판단한다. 같은 조건으로
   비교할 수 없는 수치를 합산 순위로 만들지 않는다.

각 축은 충족/부분/미충족/판정불가와 근거로 기록한다. 종합 점수를 임의로 합산하지
않으며 두 정책의 손익이 엇갈리면 그대로 보고한다. 소표본이므로 통계 우월성 주장 금지.

## 추가 발견 시험의 발동 조건

제안군이 두 과제 모두에서 실제 최종물을 제출하고, 핵심 가정 없이도 목적을 충족하는
근거 또는 가정을 지탱하는 근거를 제시하며, 재료를 활용한 구성/선택의 중대한 공백이
없을 때에만 ‘재료 제공 시 판단 가능’으로 분류한다. 기존군 대비 우월성과는 별개다.
운영자의 기술 평가에 따라 조건을 기록하고 불명확하면 추가4회를 자동 실행하지 않는다.
시작하더라도 동일 과제의 재료 목록을 뺀 조건으로만 비교하고 앞 답안을 노출하지 않는다.
새로운 독립 일반화 평가를 했다고 부르지 않는다. 총8회/6시간 한도는 유지한다.

실패/시간 초과/인프라 오류는 구분해 보존한다. 시험 도중 발견한 결함을 해당 참가자의
소스에만 고치지 않는다. 안전한 종료와 증거 보존 후 새 시험 필요성을 별도 판단한다.
