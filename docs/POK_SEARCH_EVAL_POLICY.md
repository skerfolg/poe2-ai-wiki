# 생성·탐색 판단 평가의 제안 정책 초안

상태: S2 준비, 아직 동결하지 않음. 제품 기본 스킬을 교체하지 않는다.
두 군은 기존 생성/조립 스킬과 동일 도구·입력·시간을 사용한다.
아래 안내만 제안군의 추가 입력으로 제공할 예정이다.

## 제안군 안내

현재 구성은 사용자 고정과 구분되는 잠정 구현이다. 사용자 목적을 지탱하는 핵심
가정과 그 가정에 의존하는 선택을 기존 설계 기록으로 연결하라. 알려지지 않은 모든
것을 나열하기보다 결론을 바꿀 수 있는 가정을 우선 조사하라.

새 관측이 핵심 가정을 약화시키면 미검증 문구를 추가하는 데서 끝내지 말고 현재
구성을 유지할 이유를 다시 판단하라. 공급을 보강한 묶음, 의존을 낮춘 구성, 해당 효과
없이도 기능하는 구성 중 목적에 맞는 대안을 비교하라. 필요한 후보 수나 도구 호출
순서는 정해져 있지 않으며, 기존 선택을 유지하는 것도 근거가 있으면 유효하다.

판단에 사용한 관측은 근거와 영향을 받는 가정/결정에 연결하라. 질문을 닫거나
설명만 갱신한 것이 근거 연결이나 재검토를 대신하지 않는다. 기존 도구의 실제 스키마와
참조를 사용하고 결과가 생성됐다는 이유로 게임 성립을 인증하지 말라.

슬롯·포인트·자원·경로를 새로 열어 주는 선택은 그것을 활용하는 동반 구성과 함께
평가하라. 단독 교체의 손해를 완성 조합의 손해로 확대하지 말고 추가 투자와 방어·
회복·조작 대가를 포함하라. 후보집합 밖/미측정은 무가치와 구분하라.

미확인 효과 없이 남는 기능을 사용자 목적과 대조하라. 자료가 부족하면 선택이
뒤집히는 조건과 필요한 관측을 남기되 임의의 가동률·가격·실전 효과를 만들지 말라.
최종 산출물에는 실제 선택·기각 근거와 불확실성의 영향을 설명하라.

## 평가자가 지킬 경계

이 문구를 잘 반복하거나 구조화 필드를 많이 채운 것을 품질 점수로 쓰지 않는다.
실제 조합과 선택이 사용자 목적을 더 잘 충족했는지 확인한다. 기존군의 자유 서술도
동등한 의미가 있으면 인정한다. 표현 차이와 실제 판단 차이를 분리한다.
