## 사용자 판정

핵심 기재를 고르고 연결하는 이유가 이전 낙제 버전보다 크게 개선됐으며 어느 정도
납득 가능하다는 사용자 평가다. 유의미한 성능 향상·최적 구성의 확인은 아니다.
토큰/작업시간 최적화는 이번 우선순위에서 미룬다. 현재 초점은 생성 품질이다.

## 보편 규칙으로 바꾸지 않을 부분

추가 정적 대조에서 기존 활5/6, 화살통3/6, 희귀 주얼 각각2/5접사를 확인했다.
목걸이는 베이스 한도4/4였고 신발은6/6이었다. 분모는 현재 프로젝트 판 규칙과
검증된 베이스/룬 조건의 한도이며 실제 추가 호환 접사·T1 가치·거래 가용성을 보증하지
않는다. 접사 부족과 배분 오류는 별개다. #226으로 검사기가 이미 계산한 이 정보를
정상 아이템에도 반환하도록 보완했고, 원본 전체의 적법성이 유지됨도 확인했다.

T1/접사 수만으로 최적성을 인증하지 않는다. 실제 부위·접사군·전용 옵션·소켓·요구치와
계산 적용을 확인한다. 공격 속도와 스킬 레벨의 우열, 특정 보조의 보편 채택률은
사용자 관측과 이번 구성의 측정 결과를 구분한다. 모든 방어 투자가 반드시 공격 시너지를
가져야 하는 것도 아니다. 독립적인 방어층의 실제 효율까지 비교해야 한다.

현재 원문에서 말리가로는 치명타 피해 보너스250% 고정과 치명타 재굴림 금지를 가진다.

치환하는 비교로 평가할 수 없다. 희귀 장갑·주얼·치명타 보조를 함께 재선정해야 한다.

## 이번 실행의 성격과 완료 기준

기존 `feedback` 경로로 사용자 원문을 호스트 응답 원장에 전달해3단계부터 개정한다.
원래 세 고정 조건을 유지하고, 기존 부품·에이전트가 정한 수치 목표는 재검토할 수 있다.
사용자 예시를 모든 빌드의 필수 목록으로 바꾸지 않는다. 외부 빌드/가이드 차단은 유지한다.
투자 상한이 정해지지 않은 상태를 저예산으로 해석하지 않고 이번에는 종결급 구현을
실제 후보로 조립한다. 획득/시장 가용성과 계산 가능한 이상 목표는 구분한다.

기존 절차가 이미 공동 변경과 자원 대안을 허용하므로 같은 원칙의 문서/강제 관문을
다시 늘리지 않는다. 우선 실제 피드백 개정에서 후보가 바뀌고 전체 손익이 개선되는지
본다. 종결 옵션의 표현·발견·적법성·계산 적용을 실제로 막는 결함이 나오면 해당
결정적 도구를 고친다. 임의 아이템 점수나 특정 기재 채택 개수를 엔진에 넣지 않는다.

산출물은 수정 앵커와 선택 이유, 원본 대비 실제 계산 차이, 슬롯을 포기/회수한 대가,
조건 유지·회복·방어의 차이와 검토용 PoB다. 같은 장면에서 기존안과 비교하고 피드백에
맞췄다는 사실과 백지 생성 품질의 일반화는 구분한다. 원본 평가를 소급 변경하지 않는다.
